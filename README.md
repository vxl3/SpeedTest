# NABDH Internet Speed Test

Arabic/English internet speed test with real ping, download, and upload requests.

## Deploy to Vercel

1. Upload this project to a new GitHub repository.
2. In Vercel choose **Add New → Project** and import the repository.
3. Click **Deploy**. No environment variables are needed.

Vercel serves `public/` as the website and `api/` as serverless endpoints.

## Local run

```bash
npm start
```

Then open `http://localhost:3000`.
